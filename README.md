# homigalado (Celso)

Toco o [Pixelmon Brasil](https://pixelmonbrasiloficial.com.br) há mais de 5 anos.
Começou como um servidor de Minecraft, virou uma rede multi-servidor com 2M+ de
downloads na Play Store, launcher próprio e um ecossistema inteiro de plugins.

Usamos Java em SpongeForge/Forge 1.12.2, que é basicamente arqueologia:
coremods disputando ordem de carregamento, mixins que quebram se você olhar torto,
e uma JVM que precisa de carinho pra segurar centenas de players sem o TPS afundar.
O resto é infra (Linux, MariaDB, Mongo, Redis) e as ferramentas internas que mantêm
tudo de pé.

Quer falar comigo? [discord.gg/pxbr](https://discord.gg/pxbr)
